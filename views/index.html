Exercise Tracker

Create users, record exercises, and view filtered exercise logs.

Example Usage:

  • POST /api/users with a username form field
  • POST /api/users/:_id/exercises with description, duration, and optional date
  • GET /api/users

Use GET /api/users/:_id/logs?from=yyyy-mm-dd&to=yyyy-mm-dd&limit=20 to filter a user's exercise log.
