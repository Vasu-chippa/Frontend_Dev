Request Header Parser Microservice

Inspect request headers and convert dates to UTC timestamps.

Example Usage:

  • /api/whoami
  • /api/2015-12-25
  • /api/1451001600000

Timestamp Example Output:

{"unix":1451001600000, "utc":"Fri, 25 Dec 2015 00:00:00 GMT"}

Enter a date string or Unix timestamp after /api/.
