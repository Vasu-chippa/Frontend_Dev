URL Shortener Microservice

Create a short link for a valid HTTP or HTTPS URL.

Example Usage:

  • POST /api/shorturl with a url form field
  • GET /api/shorturl/1 redirects to the saved URL
  • /api/whoami
  • /api/2015-12-25
  • /api/1451001600000

This service also provides timestamp and request-header APIs.
